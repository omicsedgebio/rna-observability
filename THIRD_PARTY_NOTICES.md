RNA Observability depends on or analyzes resources produced by other projects.
Those resources are not relicensed under the repository's Apache-2.0 license.

## SG-NEx

SG-NEx data are recorded by this project as CC BY-NC 4.0. The repository does
not redistribute the underlying SG-NEx sequencing datasets.

## miniQuant

The project uses a pinned upstream miniQuant implementation for a prespecified
K-value calculation. miniQuant is recorded as PolyForm Noncommercial 1.0.0.

The miniQuant source is not vendored in this repository. Project scripts invoke
a separately acquired pinned upstream source copy from an ignored local cache.

## GEO structure resources

GEO accessions used or evaluated by this project retain their source-specific
terms. Public availability through GEO is not treated as a blanket
redistribution license.

## LongBench

LongBench remains procedurally locked for external validation. Catalog metadata
records CC BY 4.0, but individual resources and component terms must be reviewed
before any authorized acquisition or redistribution.

See `docs/data_reuse_and_licensing.md` for the project's source-specific rights
