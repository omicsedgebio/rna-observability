# Phase 3A mapping failure root cause

Phase 3A did not find zero biological transcript overlap. It found zero **validated** A/B mappings because the GSE145805 K562 processed file did not pin its source transcript GTF or FASTA. The file uses Ensembl-like versioned IDs and reported lengths, but that evidence cannot establish exon or sequence equivalence to SG-NEx Ensembl 91. The conservative D classification for 65,956 exact-ID/equal-length records was therefore appropriate. [GSE145805 GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE145805) describes hg38 mapping but does not identify an exact transcript release for this processed file.

The mutually exclusive Phase 3A row audit, regenerated by `scripts/phase3b_mapping_failures.py`, covers 200,310 SG-NEx GTF transcripts:

| Observed category | Count | What is established |
|---|---:|---|
| No stable identifier overlap | 134,295 | No processed GSE145805 stable-ID candidate |
| Exact ID and equal reported length but source definition unavailable | 65,956 | Candidate only, neither exon nor sequence validated |
| Reported length mismatch at stable ID | 59 | Material discrepancy, source-specific cause unknown |

Confirmed version-only, exon-coordinate, sequence, annotation-build, identifier-semantics, preprocessing and incorrect-source-annotation failures are each **zero confirmed**, not zero occurring. Source definitions are absent, so these mechanisms cannot be counted independently. A diagnostic 1,094 SG-NEx processed IDs had missing versions recovered uniquely from the Ensembl 91 GTF; this is a target-side preprocessing detail, not an explanation for the 65,956. Phase 2 had also treated 26 pseudoautosomal suffix cases as ambiguous when a version-stripper collapsed `_PAR_Y`; Phase 3A corrected the key. The new Phase 3B Ensembl 88 rescue is a different dataset, GSE132099, and does not retroactively assign GSE145805 an Ensembl 88 annotation.

The per-category audit is `results/tables/mapping_failure_categories.tsv`. Gene symbols were never used to resolve mappings. Additional source GTF/FASTA evidence is still needed before GSE145805 D records can be promoted.
