# Transcript-end endpoint feasibility

The SG-NEx processed expression object contains transcript-level totals and workflow-specific normalized estimates. It does not contain per-transcript, strand-aware aligned start and end coordinates. The SG-NEx project documentation identifies raw reads, aligned BAM files, bigWig coverage tracks and bigBed annotation tracks as the resources from which coverage and transcript-end metrics could be reconstructed ([SG-NEx data repository](https://github.com/GoekeLab/sg-nex-data/blob/master/README.md)).

Consequently, 5-prime completeness, 3-prime completeness, coverage asymmetry and full-length recovery cannot be constructed defensibly from the current processed matrices alone. No raw FASTQ/BAM transfer was made in Phase 3C. A future implementation would need strand-aware alignment files or equivalent coverage tracks, a fixed annotation, transcript assignment rules, end tolerances and explicit handling of internal priming and alternative transcript ends. The required raw-data footprint must be estimated from the selected library manifests before any transfer. These endpoints remain exploratory and are not used for cohort selection or endpoint choice.
