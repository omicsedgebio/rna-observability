# Zero-aware K562 platform endpoint - pre-structure design

The Phase 3A signed log abundance contrast with an offset is rejected as the primary endpoint. Among independently expression-eligible transcripts, 56.8% had all-zero ONT direct-RNA values and the median contrast moved by more than 5 log2 units between fixed 0.01 and 1 TPM offsets. An arbitrary pseudocount would define much of the apparent phenotype. The following design uses only SG-NEx quantification and replicate behavior, without structure identifiers, coverage or reactivity.

Use the same Ensembl 91 transcript index for SG-NEx Salmon short- and long-read `normEst`, reclose each library to 1,000,000 across that index, and keep observed zeros distinct from missing output rows. The independent abundance eligibility source is K562 Illumina Rep3 with reclosed TPM at least 1. Illumina outcome observations are Rep4 and Rep5; ONT direct-RNA observations are preparations 1, 4, 5 and 6. These are not assumed to be paired aliquots. Technical runs within a preparation require depth aggregation before this rule if present.

For a transcript in each library, detection is `TPM >= 1`. A platform is **detected** if Illumina meets this rule in 2/2 outcome preparations or ONT in at least 3/4. A platform is **absent** if 0/2 or 0/4 meet it, respectively. Every intermediate support count is **indeterminate**, not absent. Among two determined platform statuses, the primary candidate is a four-category outcome: BOTH, ILLUMINA_ONLY, DIRECT_RNA_ONLY or NEITHER. Any indeterminate platform makes the transcript category INDETERMINATE and excludes it from the primary four-category fit; its count is reported. This is protocol/quantifier-specific detectability, **not true error** or molecule absence.

Conditional on BOTH, the prespecified quantitative secondary is median within-library transcript abundance percentile in ONT minus median percentile in Illumina, with ranks calculated over the fixed reference universe separately for each library. It has no pseudocount and does not require a shared molar scale. A further exploratory positive-only log2 TPM ratio is defined only when every included platform-library estimate is strictly positive; zeros make it undefined, never offset. Isoform-fraction disagreement remains exploratory with nonzero gene denominators. Spike-in true relative error remains a separate endpoint only after molecule mixture truth and sample linkage are verified.

The measurement-only threshold grid was 0.1, 1 and 5 TPM, with Illumina 2/2 and ONT 2/4, 3/4 or 4/4 support. At 1 TPM, Illumina pairwise call agreement is 0.869, mean ONT pair agreement 0.880 and disjoint ONT-pair supported-call agreement 0.920 in the independently expressed 49,309-transcript universe. The 3/4 ONT rule reduces single-library calls without discarding as many supported profiles as 4/4. At the selected rule, counts are BOTH 11,731, ILLUMINA_ONLY 20,201, DIRECT_RNA_ONLY 315, NEITHER 3,687 and INDETERMINATE 13,375. These counts describe measurement properties, not structure associations. All grid counts are in `results/tables/zero_aware_threshold_qc.tsv`.

Quantifier sensitivity remains problematic: Illumina RSEM versus Salmon status agreement is 0.861 on 198,569 complete rows. ONT NanoCount output is sparse, with only 30,445 rows complete across four preparations; on that selected subset NanoCount versus Salmon status agreement is 0.519 after separate closure. The latter is not a fair missing-equals-zero comparison, but it shows the ONT detection phenotype is quantifier sensitive. No four-category primary outcome is frozen. Before a freeze, reproduce the rule on a fixed, common-output universe under a method with defensible long-read zero semantics and assess whether an algorithm-independent technology phenotype is identifiable.
