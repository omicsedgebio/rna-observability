# GSE132099 K562 in-vivo icSHAPE feasibility

[GEO GSE132099](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE132099) identifies K562 cells and three biological in-vivo icSHAPE-treated replicates, with three DMSO controls in a 14-sample study. [GEO sample processing metadata](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3842467) explicitly states Bowtie2 alignment to the **Ensembl Release 88 GRCh38 transcriptome** and describes the processed series file as transcript ID, length, RPKM and per-position enrichment scores. The processed in-vivo scores pool the experiment; this file does not expose three independent per-transcript score vectors. The study is a different laboratory/preparation from SG-NEx.

Only `GSE132099_icSHAPE_invivo.out.txt.gz` was downloaded. It is 22,840,529 bytes, SHA256 `d2d168e235faf9cdc3169c96ffc046635695bf1bec5e1e63a4066cd283cd198d`, retrieved 2026-09-23 from the exact GEO supplementary URL in `metadata/phase3b_resources.tsv`. It is cached under `.cache/phase3b/structure/`, not committed. It contains 16,295 unversioned Ensembl transcript IDs and 20,354,101 reported positions, of which 19,188,788 are numeric rather than `NULL`. Reported length equals the number of position fields on every line. Numeric values span -299.933 to 4.444, so they cannot safely be interpreted as bounded base-pairing probabilities or silently clipped to 0-1. GEO calls them enrichment scores. Transcript-level assay RPKM is metadata, not a structure feature or a sequencing outcome covariate.

The release-pinned bridge yields 16,268 A mappings, 17 C, 5 D and 5 E; 16,055 A profiles pass at least 50 callable bases and at least 0.5 callable fraction. This is a nontrivial development candidate but only 8.1% of the covariate-complete Ensembl 91 universe is usable. Sequence/exon validation and availability details are in `docs/ensembl88_to_91_bridge.md` and `docs/structure_estimand.md`.

GEO offers public access for academic research. Dataset-specific redistribution and future commercial terms were not found in the displayed primary metadata; record them as unclear rather than assuming permission. The downloaded file is not redistributed in this repository.
