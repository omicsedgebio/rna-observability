# Phase 3C structure-only reproducibility diagnosis

Status: completed as a structure-only diagnostic. This analysis did not read SG-NEx abundance, detection, disagreement, residuals or LongBench outcomes. It compares only independent K562 structure assays, reference identity and structure assay callability.

The Phase 3B cross-study transcript-median result used 75 profiles from 71 genes and had Spearman 0.196 (gene-bootstrap 95% interval -0.063 to 0.408). We will separate attrition at each stage: GSE149767 in-vivo `.rx` profile, same-RefSeq fSHAPE map with full base sequence, unique exact Ensembl 91 sequence, GSE132099 class-A release bridge, both-assay transcript coverage, and nucleotide positions called in both assays. The fSHAPE map is used only as a sequence proxy for identity; its reactivity is not substituted for in-vivo reactivity. GSE149767 lacks a pinned RefSeq release, which remains a qualification.

For the same exact full-length sequence and positions, compare within-transcript nucleotide ranks of GSE132099 pooled in-vivo enrichment against each of the two GSE149767 in-vivo `.rx` columns. Report per-transcript Spearman only with at least 50 jointly callable positions and nonconstant values in both vectors. Also report GSE149767 replicate-vs-replicate nucleotide Spearman on their joint mask as an assay-internal reference. Predefine first and last 100 nucleotides as end windows; analyze them only if each has at least 30 jointly callable positions. For categorical local agreement, define upper-quartile positions separately within each profile's callable positions and report observed overlap divided by jointly callable positions, with the independent-rank 1/16 expectation as context. These are diagnostics, not new features selected for a sequencing test.

Report medians, interquartile ranges, number of eligible transcripts/genes and the overlap distribution. A high within-study replicate correlation coupled with poor cross-study correlation suggests study/chemistry/normalization differences; uniformly poor correlation suggests insufficient information or positional mismatch. Do not choose a future Model D feature from these results alone. The future structure-feature specification and its validation limit must be declared before any structure-versus-sequencing analysis.

Phase 3C found 10,896 GSE149767 in-vivo profiles, 10,878 with a unique map, 353 exact class-A sequence matches and 72 profiles passing the joint callable-position rule (68 genes). Across those 72 profiles, the median nucleotide Spearman correlation between studies was 0.321, versus 0.679 between the two GSE149767 replicate columns. Median upper- and lower-quartile overlap for the cross-study comparison was 0.126 and 0.100, respectively, with an independent-rank context of 0.0625. This does not establish a reproducible cross-study structure feature. The stricter 72-profile nucleotide diagnostic differs from the earlier 75-profile transcript-median summary and remains independent of sequencing outcomes. Results are in `results/tables/structure_reproducibility.tsv` and `results/tables/structure_reproducibility_diagnosis.json`.
