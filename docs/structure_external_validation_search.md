# Independent experimental structure validation search

Search updated 2026-09-23 using PubMed/publisher methods, GEO and linked SRA records, ENCODE, project repositories and public structure resource pages. Only catalog metadata and methods were inspected; no LongBench outcome or figure was opened. Classification concerns **incremental structure contribution**, not mere availability of a structure assay.

| LongBench | Locked ONT/PacBio/Illumina benchmark in lung-cancer cell lines | UNSUITABLE for current structure increment | No verified matched structure assay; compatibility metadata only, outcomes remain locked |

No **STRONG** independent dataset was established that simultaneously has independent experimental structure, validated matching transcript definitions, paired or well-nested Illumina and ONT direct-RNA abundance, and processed transcript-level measures. The strongest alternative is a three-axis program after a genuine freeze: (1) validate **sequencing behavior** on a locked independent platform benchmark, (2) validate **structure-feature reproducibility** between independent K562/HepG2 structure assays after transcript-definition validation, and (3) seek an independently generated structure plus matched multi-platform cohort for the **incremental structure contribution** itself. Evidence for (1) or (2) does not imply (3). PORE-cupine warrants a methods/processed-data audit before being upgraded.
