# Independent experimental structure validation search

Search updated 2026-09-23 using PubMed/publisher methods, GEO and linked SRA records, ENCODE, project repositories and public structure resource pages. Only catalog metadata and methods were inspected; no LongBench outcome or figure was opened. Classification concerns **incremental structure contribution**, not mere availability of a structure assay.

No **STRONG** independent dataset was established that simultaneously has independent experimental structure, validated matching transcript definitions, paired or well-nested Illumina and ONT direct-RNA abundance, and processed transcript-level measures. The strongest alternative is a three-axis program after a genuine freeze: (1) validate **sequencing behavior** on a locked independent platform benchmark, (2) validate **structure-feature reproducibility** between independent K562/HepG2 structure assays after transcript-definition validation, and (3) seek an independently generated structure plus matched multi-platform cohort for the **incremental structure contribution** itself. Evidence for (1) or (2) does not imply (3). PORE-cupine warrants a methods/processed-data audit before being upgraded.
# Phase 3B update, 2026-09-23

The [GSE132099 K562 in-vivo icSHAPE series](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE132099) is a **STRONG development structure resource** for annotation compatibility because its Ensembl 88 GRCh38 mapping is explicit and 16,055 covered transcripts bridge exactly to SG-NEx Ensembl 91. It is not independent sequencing validation. The [GSE149767 K562 series](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE149767) is **WEAK independent structure-feature validation**: RefSeq-based processed profiles lack a pinned release, only 724 have a unique exact Ensembl 91 sequence proxy from same-accession fSHAPE maps, and only 75 high-coverage profiles overlap GSE132099 for structure-to-structure comparison. The cross-study median-reactivity Spearman is 0.196 (gene-bootstrap 95% interval -0.063 to 0.408), so reproducibility is not established. This result says nothing about structure's predictive contribution to sequencing behavior.

K562 [ENCODE ONT direct RNA ENCSR917JIA](https://www.encodeproject.org/experiments/ENCSR917JIA), [PacBio ENCSR589FUJ](https://www.encodeproject.org/experiments/ENCSR589FUJ), [ENCSR526TQU](https://www.encodeproject.org/experiments/ENCSR526TQU) and untreated Illumina [ENCSR000AEP](https://www.encodeproject.org/experiments/ENCSR000AEP) or [ENCSR000AEM](https://www.encodeproject.org/experiments/ENCSR000AEM) may independently validate sequencing behavior after annotation/preparation audits. They do not by themselves independently validate an incremental structure contribution. No verified public independent study with matched transcript-level in-vivo structure and a harmonized replicated Illumina/ONT phenotype was established in this phase. LongBench outcomes were not accessed.
