# Exact SG-NEx reference resolution

SG-NEx pins Homo sapiens Ensembl release 91 on GRCh38. We retrieved the exact [Ensembl 91 GTF](https://ftp.ensembl.org/pub/release-91/gtf/homo_sapiens/Homo_sapiens.GRCh38.91.gtf.gz), [cDNA FASTA](https://ftp.ensembl.org/pub/release-91/fasta/homo_sapiens/cdna/Homo_sapiens.GRCh38.cdna.all.fa.gz), [ncRNA FASTA](https://ftp.ensembl.org/pub/release-91/fasta/homo_sapiens/ncrna/Homo_sapiens.GRCh38.ncrna.fa.gz) and [primary assembly genomic FASTA](https://ftp.ensembl.org/pub/release-91/fasta/homo_sapiens/dna/Homo_sapiens.GRCh38.dna.primary_assembly.fa.gz). We also retrieved SG-NEx's pinned transcriptome FASTA and spike-in-augmented GTF/FASTA. Exact URLs, byte counts, UTC acquisition dates, SHA256 values, reuse notes and ignored cache paths for all seven resources are in `metadata/reference_resources.tsv`. This is the immutable reference manifest; no newer annotation was substituted.

The GTF provides transcript-to-gene mapping, biotypes, chromosome, strand and exon coordinates. GTF coordinates are 1-based inclusive; code stores exons 0-based half-open. Ensembl names human chromosomes `1` through `22`, `X`, `Y`, `MT` plus assembly scaffolds, while the SG-NEx augmented GTF uses a `chr` prefix. The comparison strips that prefix only for chromosome identity and preserves `_PAR_Y` transcript suffixes as distinct loci. The exact reference comparison covers 200,310 GTF transcripts; 199,216 have equal Ensembl FASTA, genome-reconstructed transcript sequence, and SG-NEx mirror sequence. All 200,310 exon definitions agree with the augmented GTF. The 1,094 remaining GTF transcripts have no matching Ensembl transcript FASTA and are excluded from sequence-feature analysis rather than imputed. The combined cDNA/ncRNA and SG-NEx mirror each contain 218,166 FASTA records because the FASTA includes records outside the inspected GTF universe.

The full `reference_transcript_validation.tsv` and feature matrix are ignored derived outputs, regenerated by `scripts/phase3a_references.py` from checksummed cached references. Large reference and derived files remain outside git. All resources were acquired on 2026-09-23; reference integrity was rechecked during interruption recovery.
