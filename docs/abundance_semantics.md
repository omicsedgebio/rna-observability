# SG-NEx processed abundance semantics

Status: resolved for the recorded workflows; cross-protocol interpretation remains limited. The pinned [SG-NEx combination code](https://github.com/GoekeLab/sg-nex-data/blob/fea2aa80b149778d7fce507867dd6754fc4f84ca/manuscript/code/utilities/CombineExpressionAcrossMethods.R) computes `normEst = estimates / ntotal * 1,000,000`. The pinned [expression-table generator](https://github.com/GoekeLab/sg-nex-data/blob/fea2aa80b149778d7fce507867dd6754fc4f84ca/manuscript/code/utilities/GenerateExpressionTable.R) first sets Salmon, RSEM and NanoCount `estimates = TPM / 1,000,000 * ntotal`. Thus `estimates` for those methods is a depth-rescaled TPM, not the original expected fragment count, and `normEst` recovers each method's TPM. Bambu instead provides assay counts, so its `normEst` is CPM-like. The 139-run audit in `results/tables/abundance_semantics_audit.tsv` found zero discrepancy from the formula.

The workflow-by-workflow record is `metadata/quantification_workflows.tsv`. Salmon short reads use quasi-mapping with mapping and sequence/GC/position bias options; SG-NEx long-read Salmon uses ONT alignments and `--ont`. The pinned Salmon 1.9.0 source indicates that ONT mode suppresses length correction. Equal TPM names therefore do not establish an identical generative measurement scale or accuracy. The selected Salmon pair permits a compositional, protocol-specific comparison after closing both outputs over the same Ensembl 91 transcript universe and declaring missing rows separately. It is **COMPARABLE_AFTER_SPECIFIED_TRANSFORMATION**, never directly comparable molecule counts. Original full-reference TPM and common-universe reclosed TPM are separate sensitivity analyses; reclosure changed the provisional log contrast by median absolute 0.432 log2 units.

RSEM short-read TPM against Salmon long-read TPM and NanoCount short/long cross-quantifier values are **RANK_OR_DETECTION_ONLY** without calibration. NanoCount output is sparse and absent rows cannot silently become zero. Bambu long-read CPM-like counts versus Salmon TPM are **NOT_DEFENSIBLY_COMPARABLE** as quantitative abundance; its detection and count-scale behavior can be a sensitivity analysis. No workflow is marked **DIRECTLY_COMPARABLE** across technologies. Across samples, TPM supports relative composition within a common annotation, but compositional shifts, effective-length handling and protocol bias prevent unqualified fold-change or truth claims.

In a complete fixed transcript index, a stored zero is a fitted/assigned zero at that depth and model, not biological absence. Zero-heavy direct RNA estimates make log contrasts highly pseudocount sensitive. Protocol-specific non-detection must be reported separately from continuous abundance. Biological preparations and laboratories differ between SG-NEx sequencing and the external icSHAPE assay.
