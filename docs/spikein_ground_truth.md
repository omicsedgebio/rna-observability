# Spike-in ground truth and possible true-error endpoint

SG-NEx supplies a small spike-in truth object with transcript ID, gene ID, mixture label and concentration, and a separate processed spike-in quantification object. The checksummed truth source and SG-NEx sample/code sources are recorded in `metadata/phase3a_source_provenance.tsv`. `metadata/spikein_truth_summary.tsv` gives all six molecule groups, numeric-truth counts and library compatibility. These are synthetic input concentrations, unlike endogenous platform agreement. The SG-NEx [sample metadata](https://github.com/GoekeLab/sg-nex-data/blob/fea2aa80b149778d7fce507867dd6754fc4f84ca/docs/samples.tsv) identifies K562 Illumina replicates 3-5 and ONT direct-RNA replicates 4-5 as receiving Sequin Mix A v1.0; direct-RNA replicate 1 and 6 lack such a documented spike. PacBio K562 contains a multi-mix cocktail. The [spike-in processing code](https://github.com/GoekeLab/sg-nex-data/blob/fea2aa80b149778d7fce507867dd6754fc4f84ca/manuscript/code/utilities/GenerateSpikeinBam.R) combines spike-in reads by mix and protocol, so those outputs are not independent biological K562 spike observations.

For a single verified mixture and quantifier, a future **true relative-abundance error** endpoint can use molecules with numeric concentrations and compatible processed estimates. Let `p_s = c_s / sum_{j in M} c_j` and `q_sp = a_sp / sum_{j in M} a_jp`, with the same fixed truth-known molecule set `M` and protocol `p`. For detected molecules define `e_sp = log2(q_sp / p_s)`; report nondetection as a separate endpoint and do not pseudocount it into accuracy. This tests within-mixture relative recovery, not absolute molecule count error. Concentration units and mixture identity must be verified from source documentation before evaluating it. Exclude 3 Sequin A v1.0, 31 SIRV E0 and 31 SIRV E2 transcripts with missing numeric concentration. The ratio endpoint is **defined but not yet evaluated**; a spike-in true-error result is unavailable in Phase 3A. Synthetic combined runs cannot supply biological-replicate uncertainty for the K562 primary comparison.

The endogenous signed Illumina versus ONT contrast is **platform disagreement**, not measurement error. Neither platform nor their consensus is treated as truth.
