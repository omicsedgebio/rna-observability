# Project instructions

This is manuscript-targeted research, not a demonstration. Preserve negative results and uncertainty.

1. No predictive modeling until the Phase 1 report is reviewed and explicitly approved.
2. Never push, publish, change repository visibility, create a release/DOI, or build the explorer without authorization.
3. Before touching LongBench, read docs/external_validation_lock.md. No external outcomes, model testing, feature selection, threshold tuning, tutorial results, or benchmark figures before an approved committed freeze.
4. Read docs/claims_register.md before drafting scientific claims. Do not claim novelty, causation, clinical utility, or a validated score.
5. Use true error only with defensible truth. Never treat a platform or consensus as truth by default.
6. Preserve sample/run/biological-replicate nesting and transcript version identity. Split genes/sequence-similarity groups together in future validation.
7. Keep annotation-only identifiability controls mandatory. Experimental structure cannot replace them.
8. No raw sequencing downloads by default. Before any transfer >approximately 5 GB report purpose, size, processed alternatives and necessity.
9. Do not commit source datasets, restricted material, caches, credentials, or generated binaries. Track provenance and hashes for authorized acquisitions.
10. Mac development; Linux canonical reproduction. All scientific outputs programmatic. No fabricated figures or results.
11. Maintain decisions, assumptions, limitations, and exposure logs. Never silently revise a frozen plan.
12. No subagents are required. Use local checks before committing.
